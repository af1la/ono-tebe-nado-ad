# Оно тебе надо

Проектная работа курса «Фронтенд-разработка» Яндекс Практикума — главная страница аукциона вещей, в которые никто не верил.

## Что сделано

- Адаптированная под макет вёрстка страницы шириной 1100px: шапка, обложка, лоты, блок «Об аукционе» и подвал.
- Семантическая разметка: `header`, `main`, `section`, `nav`, `article`, `address`, `footer`.
- Именование классов по методологии БЭМ.
- Раскладка на гридах (шапка, «Об аукционе», подвал) и флексбоксах (меню, карточки лотов, соцсети).
- Переиспользуемый полупрозрачный оверлей на обложке и карточках (абсолютное позиционирование, `z-index`).
- Подключение шрифта Raleway через `@font-face` в форматах WOFF2 и WOFF.
- Ссылки на телефон и почту через `tel:` и `mailto:`.

## Технологии

HTML5, CSS3 (Flexbox, Grid, позиционирование).
